# 🌐 VPN 切替マネージャー

Windows 上で複数の VPN / プロキシクライアントを管理・切替するための PowerShell スクリプトです。

## 対応クライアント

| No. | クライアント | 種別 |
|-----|-------------|------|
| 1   | 农夫山泉 farmer | VPN (TUN 対応) |
| 2   | Clash Verge | VPN (TUN 対応) |
| 3   | v2rayN | プロキシ |
| 4   | Quark | プロキシ |

## 機能

- **ワンキー切替** — 選択したクライアントを起動し、他を自動停止
- **残留プロセス自動検出・クリーンアップ** — GUI が閉じているのにバックグラウンドで動いているプロセス/サービスを掃除
- **システムプロキシ自動設定** — プロキシポートを Windows のインターネット設定に自動反映
- **TUN MTU 自動調整** — TUN アダプターの MTU を 1400 に設定

## 使い方

### 起動方法

1. **`VPN切替.bat` をダブルクリック**（管理者権限が自動で要求されます）
2. または PowerShell を**管理者として実行**し、以下を入力：
   ```powershell
   & "e:\codingsum\ccproject\randomitems\vpnswitch\vpn-switcher.ps1"
   ```

### 操作方法

- `1` ～ `4` で起動したいクライアントを選択
- `C` で残留プロセスのクリーンアップ
- `Q` で終了

## 注意事項

- **管理者権限が必須**です（サービスの起動/停止、TUN 設定のため）
- 各クライアントの実行ファイルパスは環境に合わせて `vpn-switcher.ps1` 内で設定してください
- システムプロキシ設定を変更するため、他のプロキシ設定ツールと競合する可能性があります

## 動作環境

- Windows 10 / 11
- PowerShell 5.1 以上
- 管理者権限
